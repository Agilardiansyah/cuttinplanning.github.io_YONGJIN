Panduan Penggunaan Sistem
1. Login

Masukkan username dan password yang sudah terdaftar untuk masuk ke sistem.

2. Dashboard

Menampilkan ringkasan Total Style, Order, Cutting Plan, dan rata-rata Fabric Utilization. Juga menampilkan 5 cutting plan terbaru.

3. Data Style / Artikel

Kelola data style (kode, nama, deskripsi). Klik tombol + Tambah Style untuk menambah data baru.

4. Data Order

Input order baru dengan memilih Style, mengisi warna, dan memasukkan Size Ratio (XS sampai 3XL). Total quantity akan terhitung otomatis.

5. Cutting Plan

Buat rencana cutting dengan memilih Order, mengisi Marker Length (m), Jumlah Lay, dan Lebar Kain. Sistem akan menghitung otomatis:

  • Fabric Used (YD) = Marker Length × Jumlah Lay × 1.0936
  • Utilization % dihitung berdasarkan parameter yang diinput
6. Update Status

Pada tabel Cutting Plan, klik ikon refresh untuk mengubah status: Belum → Proses → Selesai

7. Laporan

Menampilkan seluruh cutting plan beserta total fabric used dan rata-rata utilization. Bisa dicetak dengan tombol Cetak PDF.

Cara Upload / Deploy Online
  1. Netlify Drop (paling mudah): Buka app.netlify.com/drop → drag folder project
  2. GitHub Pages: Upload ke repository GitHub → Settings → Pages
  3. Vercel: Import project dari GitHub

Lihat file TUTORIAL.md untuk panduan lengkap langkah demi langkah.
